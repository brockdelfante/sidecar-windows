# Sidecar for Windows

Discovery-call companion for Microsoft Teams desktop. Questions on the board, live notes, wrap-up summary, past call archive.

## Download

Get the zip from **[Releases](https://github.com/brockdelfante/sidecar-windows/releases/latest)** — file `Sidecar-Windows.zip` (~1.1 GB).

This is a folder, not a Setup wizard. There is nothing else to install.

1. Unzip `Sidecar-Windows.zip` somewhere you keep apps (for example `Documents\Sidecar`).
2. Open that folder. Leave every file in it — do not lift `Sidecar.exe` out on its own.
3. Double-click **Sidecar.exe**.

Windows may say the app is unrecognised (it is not from the Microsoft Store). Choose **More info → Run anyway**.

First open can take about a minute while the built-in coach loads. After that it stays on this PC.

## Use with Teams desktop

- Headphones on. That keeps Them out of your mic.
- In Teams desktop: Settings → Devices → Speaker → CABLE Input, VoiceMeeter, or Stereo Mix.
- In Sidecar: **Listen to this PC** (or pick that input once — Sidecar remembers it).
- Sidecar does not share your screen into the meeting.

## On the home screen

- Discovery questions are on the board. Tick anything you already know.
- Wrap a call (or let Sidecar hear wrap-up talk). The note is saved in **Past notes** with start and end time.
- Open a past note from the Past notes card at the top, or the Past notes button in the header.

Keep the whole folder together when you move or copy it.
